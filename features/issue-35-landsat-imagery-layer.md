# Issue #35 — Satellite Imagery (Landsat 8/9) Base Layer

An optional satellite imagery base layer is available in the map Options panel under **Satellite Imagery**. When enabled, cloud-minimized Landsat 8/9 true-color imagery is displayed for predefined mountainous regions (Wasatch/Front Range, Cascades/Sierra Nevada, Appalachians, Northern Rockies). The imagery is pan-sharpened using the Brovey transform for improved detail at higher zoom levels and supports resolutions from 640 m/px down to 20 m/px.

The layer is rendered below VFR sectional charts (zIndex -1) so it acts as an alternative base layer. Users can toggle sectionals off and imagery on to get a real-world terrain view for flight planning. The imagery is built from an April–October 2024 time window biased away from snow cover. Attribution is displayed as "U.S. Geological Survey."
